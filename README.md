# Obscura

A picture-guessing game: a movie scene, an actor or an anime character starts distorted and clears up over 30 seconds. Name it early for more points.

- One static file (`index.html`), no build step.
- Anime characters and series load from AniList (no key needed).
- Movies and actors load from TMDB. Add a free TMDB API key under "Settings and credits" in the game.

Pictures are requested live from those services and belong to their rights holders. This product uses the TMDB API but is not endorsed or certified by TMDB.
